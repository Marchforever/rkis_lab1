Справочник базовых команд Git:
1. git init — создание локального репозитория
2. git status — статус отслеживаемых и неотслеживаемых файлов
3. git add — подготовка изменений к коммиту (staging)
4. git commit — фиксация изменений в истории проекта
5. git branch — управление ветками
6. git checkout — переключение между ветками
7. git merge — слияние веток
